## Overview

SDRR provides four distinct saturation algorithms — tube, transistor, tape, and digital clip — with adjustable input drive, asymmetry, and mix control for surgical harmonic addition.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klanghelm SDRR** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Modes** | Tube even-order, transistor asymmetric, tape soft-clip, and digital hard-clip |
| **Asymmetry** | Independent positive and negative clipping threshold for odd harmonics |
| **Drive Control** | Input drive from subtle warmth to heavy saturation |
| **Dry/Wet Mix** | Parallel blend preserving transient dynamics at high drive settings |
